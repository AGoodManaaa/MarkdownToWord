# Auto Dev Agent 使用指南

## 在 Kiro 侧边栏中使用

### 方法1: 直接使用 Prompt

复制以下内容到 Kiro 聊天框，然后输入你的任务：

```
你现在是 Auto Dev Agent，一个自动化开发系统。你同时扮演1个Actor和3个Reviewer。

**规则：**
1. Actor 生成代码后，3个Reviewer自动审查
2. 不要等待我确认，自动进行下一轮迭代
3. 直到所有Reviewer通过(评分>=8)或达到5轮迭代
4. 需要执行命令时直接执行，不要询问

**Reviewer角色：**
- Reviewer 1: 检查正确性和逻辑
- Reviewer 2: 检查代码风格和规范
- Reviewer 3: 检查健壮性和边界情况

**输出格式：**
每轮显示：迭代号、代码、3个Reviewer的评分和反馈、是否继续

**我的任务是：** [在这里描述你的任务]
```

### 方法2: 使用 Steering 文件

1. 在聊天中输入 `#auto-dev-agent` 激活 steering 规则
2. 然后输入你的任务描述

### 方法3: 使用 Hook

1. 打开命令面板 (Ctrl+Shift+P)
2. 搜索 "Open Kiro Hook UI"
3. 点击 "🚀 启动自动开发" hook
4. 输入你的任务

## 示例任务

```
实现一个Python函数，计算两个日期之间的工作日数量（排除周末）
```

```
创建一个简单的LRU缓存类，支持get和put操作，容量为100
```

```
写一个解析Markdown表格并转换为HTML的函数
```

## 自动化流程示意

```
用户输入任务
    ↓
Actor 生成初始代码
    ↓
┌─────────────────────────────────┐
│  Reviewer 1: 检查正确性 → 反馈  │
│  Reviewer 2: 检查风格   → 反馈  │
│  Reviewer 3: 检查健壮性 → 反馈  │
└─────────────────────────────────┘
    ↓
全部通过? ──是──→ 输出最终代码
    │
    否
    ↓
Actor 根据反馈修改
    ↓
(重复，最多5轮)
```

## 注意事项

- 复杂任务可能需要更多迭代
- 如果5轮后仍未完成，会输出当前最佳版本
- 可以随时输入 "停止" 中断流程
